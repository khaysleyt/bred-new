# BRED multilingual pages

French remains the editorial source and default language. English and Dutch are generated as real static HTML files by:

```text
python tools/generate_localized_pages.py
```

Production does not require Python. Deploy the generated HTML, shared `css/`, `js/`, `assets/`, and the single `api/contact.php` endpoint.

| French | English | Dutch |
| --- | --- | --- |
| `/` | `/en/` | `/nl/` |
| `/a-propos/` | `/en/about/` | `/nl/over-ons/` |
| `/equipe/` | `/en/team/` | `/nl/team/` |
| `/projets/` | `/en/projects/` | `/nl/projecten/` |
| `/projets/smart-tourism/` | `/en/projects/smart-tourism/` | `/nl/projecten/smart-tourism/` |
| `/contact/` | `/en/contact/` | `/nl/contact/` |

The current generated links use `/bred-test/`. Before production deployment, set `TEST_BASE = "/"` in the generator, regenerate, remove `noindex, nofollow`, and verify canonical, hreflang and sitemap URLs.

All visual assets, CSS, animation scripts and the PHP endpoint are shared. Dynamic contact-form copy is selected from the validated `fr`, `en` or `nl` language identifier; it never changes the recipient whitelist.
